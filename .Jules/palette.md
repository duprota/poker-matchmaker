## 2024-06-10 - Add Missing ARIA Labels to Game Header Icon Buttons
**Learning:** Found several icon-only buttons in the game header that lack accessible `aria-label` or `title` attributes. This is a common accessibility issue for users with screen readers or those who rely on hover states to understand icon meanings.
**Action:** Always add descriptive `aria-label` and `title` attributes to icon-only buttons to maintain accessibility and usability standards.
