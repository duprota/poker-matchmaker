## 2024-05-15 - Dual-Labeling Icon Buttons
**Learning:** For `Button` components from Shadcn UI that are primarily icon-based (`size="icon"`), providing both an `aria-label` (for screen readers) and a `title` (native tooltip on hover for sighted users) significantly improves accessibility and usability.
**Action:** Always implement a dual-labeling approach (`aria-label` and `title`) when enhancing icon-only buttons to ensure a complete accessibility profile.
