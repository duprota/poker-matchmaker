## 2024-07-05 - Icon Button Tooltips
**Learning:** Relying solely on icons for button actions can leave some users, especially those using screen readers, without context. Adding native `title` and `aria-label` attributes provides immediate visual tooltips and screen reader support without needing external tooltip components.
**Action:** Always include `aria-label` and `title` attributes on icon-only buttons for consistent accessibility and usability.
