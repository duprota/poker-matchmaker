## 2026-07-11 - Adding Tooltips and ARIA Labels to Navigation Menu
**Learning:** The mobile hamburger menu has no 'aria-label', making it inaccessible for screen readers. Some other generic icon buttons might be lacking aria labels as well.
**Action:** Add 'aria-label' and 'title' or tooltip to icon-only buttons like the mobile Navigation menu to improve accessibility and provide hover feedback on desktop.
